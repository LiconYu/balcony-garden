# 阳台藤本植物种植方案

## 项目简介

针对深圳东北朝向、0.8m×2m窄阳台的藤本实用植物种植方案。

## 阳台条件

- 朝向：东北
- 尺寸：0.8m（进深）× 2m（长度）
- 种植区：最左侧 0.45m × 0.8m
- 晾衣架：1.2m（中间）
- 光照：上午斜射光，半阴环境

## 种植布局

4个自吸水种植盆（44×18.8×20cm）沿进深一字排开：

| 盆 | 位置 | 植物 | 种植方式 |
|----|------|------|---------|
| 盆1 | 最靠栏杆 | 常春藤 | 买苗 |
| 盆2 | 第二排 | 留兰香薄荷 | 播种 |
| 盆3 | 第三排 | 紫根细叶韭菜 | 买韭菜根 |
| 盆4 | 最靠墙（光照最好） | 木耳菜 | 播种 |

> 光照从外到内递增，需光多的植物放内侧。

## 种植工具

- 小铲子/耙子
- 喷壶（细雾）
- 90cm种植支架（木耳菜用）
- 园艺扎带
- 剪刀（厨房剪刀即可）

## 用土与施肥

- 营养土：每盆约10L，4盆共约40L（买2袋30L）
- 缓释肥：每盆15-20g（一小把），3个月一次
- 通用营养液：每2周一次（可选）

## 种植时间线

| 时间 | 里程碑 |
|------|--------|
| Day 1 | 装土、种植、播种 |
| Day 3-7 | 木耳菜出芽 |
| Day 7-14 | 薄荷出芽、韭菜发芽 |
| Day 14 | 间苗、插支架 |
| Day 30 | 木耳菜可采收 |
| Day 45-60 | 薄荷可摘叶 |
| Day 60 | 韭菜可割第一茬 |
